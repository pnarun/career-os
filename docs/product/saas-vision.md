# SaaS vision

## Positioning

Career OS aims to be the **operating system for job search** — not another job board, but the intelligence layer that sits across boards.

## Target user

- Active job seekers (tech, knowledge work)
- Users willing to connect LinkedIn via extension for better results
- India and remote-friendly role focus (configurable)

## Business model (direction)

| Tier | Concept | Status |
|------|---------|--------|
| Free / beta | Core scans with limits | **Current** |
| Pro | More scans, priority providers | **Planned** |
| Teams | Recruiter/cohort features | **Planned** |

## Why modular distributed backend matters for customers

- **Reliability** — heavy scanning does not slow login or dashboard.
- **Scale** — more workers can be added as user base grows.
- **Transparency** — enterprise customers can eventually dedicate workers.

## Roadmap themes (honest)

1. More reliable provider coverage
2. Faster realtime updates
3. Deeper apply automation
4. Team/workspace features
5. Enterprise SSO and compliance
